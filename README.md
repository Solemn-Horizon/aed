# 研急救之策，筑护城之心 · 扬州市 AED 安全保障项目实践

一个**单文件网页演示**，用浏览器打开即可放映。视觉语言按苹果发布会的三条原则重做（局部高亮 / 逐点展示 / 保持一致）：底色为深空渐变，文案用银白金属字，强调色只留给关键数字。

---

## 怎么打开

**方法一（最简单）**：双击 `index.html`，或右键 →「打开方式」→ Chrome / Edge。

**方法二（推荐，全屏更干净）**：打开后按 `F` 进入全屏。

> 无需联网、无需安装任何东西。所有字体用的是系统自带字体，动画是纯 CSS。

## 这版比 PPT 版多了什么

PPT 格式做不到、但网页版实现出来的效果：

| 效果 | 说明 |
|---|---|
| **真·渐变文字** | CSS `background-clip:text`，粉→紫完美过渡（PPT 里是注入的 XML，兼容性打问号） |
| **极光光晕背景** | 三团光晕 8–12 秒缓慢流动，画面"在呼吸" |
| **数字滚动计数** | 第 2 页的 `6` 和 `8–15` 从 0 滚上去 |
| **逐字打字机** | 第 7 页那句「这个我还真不知道。」一个字一个字浮现，带闪烁光标 |
| **镜头推近** | 封面和结尾的主角文字从 0.9 倍放大到位，模拟运镜 |
| **时间轴生长** | 第 5 页的粉色进度线从左向右长出来 |
| **丝滑转场** | 每页 opacity + scale 双属性缓动（`cubic-bezier(.16,1,.3,1)`，即 expo out） |
| **元素错峰入场** | 每页元素间隔 160ms 依次浮现，不是一起蹦出来 |

## 想改内容怎么办

用记事本 / VS Code 打开 `index.html`，直接搜要改的文字改掉就行。几个常用位置：

- **改文字**：搜索 `data-notes` 附近，每页是一个 `<section class="slide">`
- **改讲稿**：每页 `data-notes="..."` 属性（用 `&#10;` 表示换行）
- **改配色**：文件顶部 `:root` 里的 `--pink` / `--purple`
- **改每页停留时长**：搜 `8000`（毫秒），是自动播放的间隔
- **改动效快慢**：搜 `--ease`，或各处的 `transition` 时长

## 可访问性

- 所有可交互元素有 `:focus-visible` 焦点环
- 尊重系统的「减弱动态效果」设置（`prefers-reduced-motion`）—— 开启后关掉光晕/打字/推镜，只保留淡入
- 正文对比度满足 WCAG AA

## 已知说明

- **字体**：中文用系统字体（PingFang SC / 微软雅黑），数字用 Inter/Helvetica。不引用外部字体，所以断网也能正常显示，但不同电脑上字形会略有差异。
- **投影建议**：16:9 屏幕全屏播放效果最佳；1280×720 也已适配（已实测）。
- 如果投影仪分辨率很低（1024×768），文字会自动缩小，不会溢出。
