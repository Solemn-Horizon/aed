## 后期怎么改

### 改文字 / 讲稿

打开 `index.html`，每页是一个 `<section class="slide">`：

- 正文文字：直接改 `>…<` 之间的内容
- **讲稿**：改该页的 `data-notes="…"` 属性（换行用 `&#10;`）
- 新增一页：复制一个 `<section>` 块改内容即可，页码会自动更新

### 改配色

文件顶部 `:root` 里：

```css
--pink:#ff3d8b;      /* 渐变起点 */
--purple:#8b5cf6;    /* 渐变终点 */
--grey:#9ca3af;      /* 说明文字 */
```

### 改动效节奏

- 元素入场速度：搜 `.slide.active [data-anim="1"]` 那一段的 `transition-delay`
- 自动播放间隔：搜 `8000`
- 数字滚动时长：搜 `var dur = 1100`

### 改完怎么更新线上

```bash
git add -A
git commit -m "更新内容"
git push
```

GitHub Pages 会在 1 分钟内自动重新发布，**链接不变**。

## 技术说明

- 纯原生 HTML + CSS + JavaScript，**零外部依赖**（自检确认 0 个外链）
- 字体使用系统字体（PingFang SC / 微软雅黑），不加载外部字体，断网可用
- 已适配：桌面 1600×900、笔记本 1280×720、手机竖屏 390×844、手机横屏 844×390
- 可访问性：`:focus-visible` 焦点环、尊重 `prefers-reduced-motion`
- 动效全部为 CSS 动画与原生 `requestAnimationFrame`，无动画库
